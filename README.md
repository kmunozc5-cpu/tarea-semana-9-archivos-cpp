# Sistema de Control de Inventario y Validación de Archivos CSV

## Descripción del Proyecto
Programa desarrollado en **C++17** para la lectura, validación estricta y procesamiento de datos de inventario provenientes de un archivo plano CSV (`datos/productos.csv`). El sistema realiza cálculos financieros del inventario, gestiona errores de formato sin interrumpir la ejecución, permite búsquedas interactivas en memoria y exporta los resultados a un archivo de resumen formal (`reportes/resumen.txt`).
